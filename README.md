# Bank Account Management System

## Project Description

A simple C program to manage a bank account. It allows the user to deposit money, withdraw money, check the balance and view account details.

## Features

- Deposit Money
- Withdraw Money
- Check Balance
- View Account Details

## Technologies Used

- C
- Structures
- Loops
- Conditional Statements

## How to Run

Compile and run the `bank_account.c` file using a C compiler.
